CORE Econ: one random paragraph per Monkeytype test

This pool contains 6,893 individual paragraph groups: 3,505 Microeconomics
and 3,388 Macroeconomics. Monkeytype chooses ONE group for each new test.
The pipe symbol separates the groups; the words within a paragraph stay
in their original order. Forewords, glossaries and equation-heavy blocks
are excluded. The individual saved paragraphs are separate from this pool.

SET UP IN MONKEYTYPE
1. Extract this ZIP in Finder. Use a normal, non-private browser window.
2. Open https://monkeytype.com/ and choose Custom, then Change.
3. If a long/book text is active, first load any ordinary CORE paragraph from
   Saved texts, then reopen Change and dismiss any remaining warning.
   Alternatively, dismiss the long-text warning
   and type one disposable character into the editor to disable book progress
   tracking. The file import below replaces that character.
4. Select the PIPE word delimiter BEFORE importing the file.
5. Choose Open file and select CORE-Random-Paragraph-Pool.txt.
6. Select Random mode.
7. Set the Sections limit to 1. Leave Words and Time limits empty.
8. Click OK to apply the active test. Do not use Save to create a named text:
   that feature flattens paragraph boundaries.

A new test or Restart Test makes a fresh random draw. Repeat Test deliberately
replays the same paragraph. Random draws can occasionally repeat.
The active settings are normally saved in this browser. Brave and the built-in
browser have separate profiles; saved texts do not automatically transfer. Loading an individual
saved paragraph replaces the active random pool; repeat the import to restore it.

SCORING LIMITATION
Monkeytype's current source marks a one-section custom test as too short/invalid
for normal result history, even if it contains many words. WPM and accuracy
still appear after typing; these tests do not contribute normal saved results.
Paragraphs longer than 100 words continue loading as you type.

VERIFY AFTER SETUP
- Change shows Random mode, Pipe delimiter and Sections = 1.
- Each test consists of one coherent paragraph with its word order preserved.
- Restart an idle test several times; at least one selection should differ.
- Reload Monkeytype, reopen Custom > Change, and confirm Random, Pipe,
  Sections = 1 and the multi-paragraph pool are still present. If not, the
  setup has not persisted even if the first test worked.
- To check the exact persisted pool size after reload: in Change, click Simple,
  then Random. The Sections field should automatically show 6893. Set it back
  to 1 BEFORE clicking OK. Do not apply the 6893-section limit.
- Your existing individually saved paragraphs remain in Saved texts.

STORAGE
The active pool requires about 2.24 million additional characters of browser
storage. If Monkeytype reports that local storage is full, or the pool disappears
after a reload, keep the paragraph library. You can download the obsolete CORE Macro Full Test from Saved texts
as a backup, then remove only that old full-book test and retry the pool import.
Do not clear the site's browsing data; that would remove the saved library.
